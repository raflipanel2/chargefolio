## Deploy
1. Upload the **contents** of this ZIP to the root of a GitHub repository.
2. In Vercel import the repository, choose Framework Preset = Other, and keep Build Command blank.
3. Connect the final production domain. If different from https://chargefolio.vercel.app, replace the old domain in **all** HTML canonical/OG/schema metadata, robots.txt and sitemap.xml.
4. Verify homepage, guides, tools, mobile menu, /ads.txt, /sitemap.xml, contact and privacy pages.
5. Submit sitemap to Google Search Console. Add site to the **correct** AdSense account (do not create duplicate personal accounts).
6. Configure legally required advertising consent when applicable. Review Privacy before going live.

## Tools
- Watt-hour Lab: stored Wh = mAh / 1000 × nominal V; usable Wh = Wh × efficiency; runtime = usable Wh / average watts. FAA category is a general U.S. informational reference, not a travel authorization.
- Power Bank Planner: equivalents = usable Wh / device battery Wh. Real charging may differ.
- Charge Habit Log: localStorage only, supports deletion and CSV export. Do not enter private identifying data.

## Editorial boundaries
The site does not certify battery safety, provide a live recall database, or instruct how to repair a damaged lithium battery. Safety-first advice cites EPA/USFA/FAA; content is educational. AdSense approval cannot be guaranteed.
